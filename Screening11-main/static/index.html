Before you start

Create a fund thesis first

A fund thesis says what you invest in (countries, stages, sectors, round size) and how much each factor counts. Every company is compared against one, so there is nothing to screen until you have it. It takes about two minutes, and you can start from a template.

Additional resources optional · up to 5

    Only needed if the deck doesn't state it clearly.

    Usually 2-4 minutes on the free tier.

    What happens

    1. Read documents. Text from the deck and your extra files.
    2. Crawl the website. Sitemap and links, ranked by relevance; robots.txt respected; broken links reported.
    3. Extract claims. Each claim keeps an exact quote, which is checked against the source.
    4. Search the web. Funding, team, traction and adverse news; sources classed as independent, self-reported or company-owned.
    5. Verify. A claim is only "verified" if an independent source confirms it.
    6. Score. Weights adapt to stage and business model; contradictions lower the score; every adjustment is explained.

    Your documents and website text are sent to Groq for analysis and search queries go to a public search engine. Nothing is stored outside this computer.
